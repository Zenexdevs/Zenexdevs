Installation guide

Four steps, start to finish

Works the same way for every mod on Zenex — Meteor Client, Glazed, RigMaster V2 and CPVP Tweaks.

1

Download the .jar file

Head to the Downloads page, pick your mod and version, and download the .jar file straight to your computer.

2

Open your Minecraft mods folder

If you're using the Modrinth App, it opens this for you automatically per-instance. Doing it manually? Open %appdata%/.minecraft/mods on Windows or ~/Library/Application Support/minecraft/mods on Mac — create the mods folder if it isn't there yet.

3

Drag and drop the .jar in

Move the downloaded .jar file from your Downloads folder straight into the mods folder. No extraction, no installer — just drop it in.

4

Launch with Fabric

Make sure Fabric API is installed, then launch Minecraft using the Fabric profile. The mod loads and enables itself automatically — no extra setup needed.
